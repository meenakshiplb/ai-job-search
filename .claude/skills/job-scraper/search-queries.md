## Location Filter

**Ideal:** Vienna (all districts) or fully remote anywhere
**Acceptable:** Vienna metropolitan area, remote Europe, remote global (fully remote, no relocation)
**Borderline:** Lower Austria (Niederösterreich) — assess commute individually
**Deal-breaker:** Roles requiring physical relocation outside Europe (on-site or hybrid outside Europe)

## Date Filter
- Include: posted within the last 14 days, OR future application deadline (Bewerbungsfrist)
- Exclude: older postings with no visible date unless the deadline is future
- Flag: "date unknown" if no date is visible

## Language Filter
- **English-language postings:** Always apply in English
- **German-language postings:** Apply in English unless the posting explicitly requires German
- **German-only postings (local firms, public sector):** Flag for review — Meenakshi's German is A2, be honest about fit

## Fit Scoring Guidance

**Boost score (+10) if role mentions:**
- Java 17, Spring Boot, REST APIs, microservices
- Docker, Kubernetes, Jenkins
- SaaS platform, enterprise software, workload automation
- AI/GenAI tooling, LLMs, prompt engineering
- Agile (SAFe, Scrum, Kanban)
- Cross-functional teams, PR reviews, technical leadership
- Fully remote with async culture

**Reduce score (-15) if role requires:**
- Physical relocation outside Europe
- Pure frontend (React, Angular) with no backend
- Junior level or < 5 years experience
- Fluent German (C1/C2) as mandatory requirement
- Pure ML/Data Science (no software engineering component)
